# План Dress V

Состояние на 20 ноября 2026 года. HTTP-цикл, канал WordPress → Hermes и закрытая WooCommerce-карточка с реальным провайдером готовы. Хронология, расположение файлов, проверки и откат описаны в [DEPLOYMENT.md](DEPLOYMENT.md). API-контракт находится в [README.md](README.md), платный контур в [OPENAI-SETUP.md](OPENAI-SETUP.md).

## Продукт и решение

Посетитель нажимает «Увидеть себя в образе» в карточке WooCommerce, загружает портрет, видит статус и получает один кадр в той же карточке. Кадр помогает выбрать реальный образ для аренды. Размер и посадку подтверждают по карточке и на физической примерке.

Выбрана генерация постановочного кадра. Портрет задаёт внешность, галерея товара задаёт костюм, индивидуальный промпт задаёт съёмку. Обычные селфи и обрезанные кадры подходят, когда лицо читается. Для сходства, которое невозможно оценить по исходнику, интерфейс должен запросить другое фото. Каталожная модель служит референсом костюма, обуви и аксессуаров. Когда важны обувь или длинный подол, нужен кадр в полный рост.

По материалам передачи проекта, послойные прототипы выявили проблемы с положением пояса и короны, сохранением объёма и остатками исходной одежды. В сравнительном прогоне через fal проверили 56 генераций, по семь моделей на восемь сочетаний портрета и образа. На этой выборке автоматическая слепая оценка поставила GPT Image 2.6 Sunburst, Bria Fibo 2 и MiniMax H3 на первые три места. Вес костюма составлял 40%, сходства 35%, съёмки 25%. Результаты относятся к сравнительному прогону fal.

## Оставшаяся работа

1. **Подключить технический контур OpenAI.** Для разработки вставного плагина WordPress/WooCommerce используем кредиты ChatGPT API и синтетические изображения. Проектный ключ установлен на Hermes, владелец подтвердил работу генерации. Usage и Credit Grants сверяют отдельно при оценке расходов. Генератор выбирается на Hermes, поэтому плагин работает через тот же HTTP API Dress V.
2. **Подключить визуальную проверку.** Таймер ограничивает весь цикл генерации и проверки. Для исправимого дефекта допускается одна дополнительная генерация. При неоднозначном результате сетевого вызова автоматический платный повтор исключён.
3. **Утвердить данные четырёх карточек.** Закрытый плагин проверен на красном костюме с двумя референсами и индивидуальным промптом. После оценки первого реального кадра утвердить выбранные ракурсы, промпт и критерии качества, затем расширить конфигурацию пилота до четырёх карточек.
4. **Закрыть оставшиеся проверки перед расширением.** Через HTTPS уже проверены форма, изоляция сессий, выдача и подтверждение удаления. Отдельно проверить поведение в браузере при отмене и закрытии вкладки, буферизацию на полном клиентском маршруте и очистку при реальной нагрузке. Снимки и результат должны оставаться вне медиатеки, CDN-кэша, журналов и истории заказов. Визуальное сходство оценивается без идентификации личности и хранения эмбеддингов.
5. **Провести закрытый пилот.** Измерить качество, задержку, расход и память с выбранным API. Реальные фото допускаются после согласования обработки. Для остановки пилота выключить флаг, затем при необходимости использовать порядок отката из [DEPLOYMENT.md](DEPLOYMENT.md).
