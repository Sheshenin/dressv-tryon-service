# Вставной плагин Dress V для WooCommerce

Активный пилот 0.1.0 доступен администраторам на карточке [«Красный костюм со шляпой»](https://best4event.ru/product/красный-денди/), ID `200`. В конфигурации сейчас один каталожный референс, вложение `201`. Действующая служба Hermes возвращает тестовый PNG. Для проверки используйте синтетический снимок.

## Установка

Поместите папку [dressv-try-on](dressv-try-on/) в `wp-content/plugins/` и активируйте **Dress V Try-On**. Нужны WooCommerce, PHP 8.1 или новее, расширения cURL и Fileinfo. Тема должна вызывать `woocommerce_single_product_summary`. У работающего PHP должен быть маршрут до `https://dressv-hermes.internal:18444`, доступ к CA по пути `/run/dressv-ca.pem` и к межсерверному ключу по пути `/run/dressv-wordpress-token`. Для временных файлов используется [отдельное хранилище PHP](../DEPLOYMENT.md#изменения-compose-для-wordpress).

Опция WordPress `dressv_pilot` задаёт одну карточку. Команда ниже рассчитана на установку с WP-CLI. На текущем сервере опция записана через загрузку ядра WordPress в PHP CLI.

```sh
wp option update dressv_pilot '{
  "product_id": 200,
  "references": [201],
  "prompt": "Create a full-length editorial portrait preserving the red outfit in the reference.",
  "required_details": ["matching red jacket and trousers", "tiger-pattern hat"]
}' --format=json
```

`references` содержит от одного до четырёх ID локальных вложений в нужном порядке. Портрет и все референсы вместе ограничены 16 МиБ. Для отключения кнопки удалите опцию `dressv_pilot` или деактивируйте плагин.

## Как проходит примерка

Форма и обработчик доступны только вошедшему пользователю с `manage_options` на настроенной карточке. Обработчик проверяет nonce, связывает задание с текущей сессией WordPress и пересылает изображение и референсы на Hermes по проверенному TLS. Браузер опрашивает WordPress и отображает PNG из ответа с `Cache-Control: no-store`. После загрузки PNG браузер подтверждает удаление. Если подтверждение теряется, сервер очищает задание по TTL.

20 ноября 2026 года по HTTPS магазина автоматизированно проверены скрытая форма для гостя, запрет гостевого запроса, форма администратора, nonce, отправка синтетического файла, полученный PNG, отказ для другой сессии и удаление результата. Клиентское поведение при отмене или закрытии вкладки остаётся отдельной проверкой.
