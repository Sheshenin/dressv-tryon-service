# Вставной плагин Dress V для WooCommerce

Версия 0.1.5 установлена на сайте БМК. Каталог подключает 203 профиля. По умолчанию примерка доступна администраторам. В конфигурации красного костюма два ракурса с тигровой шляпой, вложения `201` и `202`. [Настройки карточки и промпт](pilots/red-dandy.json).

## Установка

Поместите папку [dressv-try-on](dressv-try-on/) в `wp-content/plugins/` и активируйте **Dress V Try-On**. Нужны WooCommerce, PHP 8.1 или новее, расширения cURL и Fileinfo. Тема должна вызывать `woocommerce_before_add_to_cart_form`. У работающего PHP должен быть маршрут до `https://dressv-hermes.internal:18444`, доступ к CA по пути `/run/dressv-ca.pem` и к межсерверному ключу по пути `/run/dressv-wordpress-token`. Для временных файлов используется [отдельное хранилище PHP](../DEPLOYMENT.md#изменения-compose-для-wordpress).

Опция WordPress `dressv_pilot` задаёт одну карточку. Команда ниже рассчитана на установку с WP-CLI. На текущем сервере опция записана через загрузку ядра WordPress в PHP CLI.

```sh
wp option update dressv_pilot '{
  "product_id": 200,
  "references": [201, 202],
  "generation_mode": "mock",
  "prompt": "Create a full-length editorial portrait preserving the red outfit in the reference.",
  "required_details": ["matching red jacket and trousers", "tiger-pattern hat"]
}' --format=json
```

`references` содержит от одного до четырёх ID локальных вложений в нужном порядке. Портрет и все референсы вместе ограничены 16 МиБ. Укажите `generation_mode: "live"` после включения внешнего провайдера на Hermes. Это меняет инструкцию в форме, а выбор провайдера остаётся на Hermes. Для отключения кнопки удалите опцию `dressv_pilot` или деактивируйте плагин.

Подробная конфигурация, референсы, промпты и перенос в репозиторий сайта описаны в [документе передачи](../SITE-HANDOFF.md).

## Доступ для посетителей

В WordPress откройте «Настройки → Dress V» или ссылку «Настройки» в списке плагинов. Флажок **«Разрешить примерку всем посетителям»** сохраняется в опции `dressv_public_access`. Снятый флажок оставляет примерку доступной только пользователям с правом `manage_options`. Установленный флажок открывает её для гостей и вошедших пользователей на всех опубликованных товарах с настроенным профилем. Доступ к самой настройке остаётся у администраторов.

Внешний загрузчик каталога подставляет профиль товара независимо от роли посетителя. Если загрузчик рисует отдельные элементы Dress V, например выбор варианта, он использует общую проверку `DressV_Try_On::can_access()`. Плагин проверяет доступ при выводе формы и при каждом AJAX-запросе. Для гостя создаётся отдельная браузерная сессия с защищённым cookie. Nonce привязан к этой сессии и конкретному товару.

## Как проходит примерка

Кнопка «Примерить образ на себя» открывает модальное окно прямо из карточки. В окне видны загрузка, анимация ожидания, 15-секундный начальный отсчёт и время, прошедшее при продолжении генерации. Форма и обработчик применяют текущий режим доступа на настроенной карточке. Форма показывает выбранное фото и готовый PNG. Замена фото очищает предыдущий результат. Обработчик проверяет nonce, связывает задание с текущей сессией пользователя или гостя и пересылает изображение и референсы на Hermes по проверенному TLS. Браузер опрашивает WordPress и отображает PNG из ответа с `Cache-Control: no-store`. После загрузки PNG браузер подтверждает удаление. Если подтверждение теряется, сервер очищает задание по TTL.

20 ноября 2026 года по HTTPS магазина автоматизированно проверены скрытая форма для гостя, запрет гостевого запроса, форма администратора, nonce, отправка синтетического файла, полученный PNG, отказ для другой сессии и удаление результата. Клиентское поведение при отмене или закрытии вкладки остаётся отдельной проверкой.
