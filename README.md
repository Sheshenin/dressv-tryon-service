# Dress V. Сервер ИИ-примерки

Сервис принимает подготовленные карточки WooCommerce и фотографии посетителей, запускает генерацию и визуальную проверку через API, затем выдаёт результат в исходную карточку. Развёртывается отдельным процессом рядом с «Гермесом».

Статус: спроектирован серверный поток и начата реализация хранилища заданий в памяти. HTTP-обвязка, провайдер и эксплуатационная настройка запланированы. Реальные запросы OpenAI включаются после подтверждения API-кредитов и допустимости использования для аудитории магазина.
