# Как подключить API-кредиты ChatGPT Pro

1. Войдите в ChatGPT с аккаунтом, которому принадлежит платная подписка. Откройте **Settings → Billing** и найдите **API credits** / **Claim**. Альтернативный вход — [Billing в OpenAI Platform](https://platform.openai.com/settings/organization/billing/overview), раздел API credits. Откройте OpenAI Platform с тем же email.
2. Выберите принадлежащую Вам API-организацию. Если отдельной организации ещё нет, можно использовать Personal API Organization. Подтвердите привязку только после проверки имени организации. Подписка должна подходить под условия OpenAI, в документации указан минимум семь дней со дня начала платной подписки.
3. Откройте [Credit Grants](https://platform.openai.com/settings/organization/billing/credit-grants) именно в выбранной организации. Убедитесь, что грант активен, и проверьте доступный остаток и дату окончания. Для Pro 100 в документации указан грант $100 за полный цикл, первый может быть меньше. Кредиты к концу цикла сгорают. Активный грант можно использовать без добавления отдельной карты в API.
4. В выбранной организации создайте проект `Dress V`. Настройте лимит расходов для пилота. Если интерфейс поддерживает **Enforce a hard limit**, включите его, а в самом приложении отдельно ограничьте число генераций и повторов. Не включайте автоматическое пополнение ради пилота.
5. Создайте ключ сервисного аккаунта проекта и ограничьте доступ нужными endpoint для генерации и визуальной проверки, если это доступно для такого ключа. Установим его напрямую в защищённый конфиг на французском сервере. Ключ не нужен в чате, исходниках, WordPress, браузере или CI.
6. После подтверждения гранта, установки ключа и проверки допустимости географии — один запрос с синтетическим входом. Сверяем Usage нужного проекта и Credit Grants организации. Только затем включаем пилот.
