# OpenAI API и кредиты Dress V

## Подтверждено 20 ноября 2026 года

В Personal Organization виден активный грант на $75 с остатком **$74,98** и сроком до 13 декабря 2026 года. В проекте Dress V включён действующий лимит **$5**, на момент сверки интерфейс показал расход **$0**. Эти цифры описывают состояние на дату проверки. Перед платным запросом нужно сверить их повторно. [Credit Grants](https://platform.openai.com/settings/organization/billing/credit-grants)

В `/etc/dressv` на Hermes есть отдельный токен WordPress и файлы TLS. Ключа OpenAI в этом каталоге нет. Адаптер `Images Edits` реализован и испытан с подменой HTTP-транспорта. Он читает ключ из `CREDENTIALS_DIRECTORY/openai-api-key`, отправляет портрет первым и не повторяет отправку вслед за сетевой ошибкой. Развёрнутая служба работает с тестовым провайдером. Платный запрос в рамках работ по этому репозиторию пока не выполнялся.

Россия отсутствует в опубликованном списке поддерживаемых территорий OpenAI. До клиентского пилота нужно подтвердить допустимость провайдера для аудитории магазина и проверить условия хранения для выбранной модели и endpoint. Первый платный вызов выполняется с синтетическими изображениями по отдельному разрешению. [Поддерживаемые территории](https://help.openai.com/en/articles/7947663-chatgpt-and-openai-api-supported-countries-and-territories) · [Условия хранения данных](https://developers.openai.com/api/docs/guides/your-data)

## Порядок подключения и проверки

1. **Сверить организацию и проект.** Открыть Credit Grants в Personal Organization и проверить срок и доступный остаток. Открыть Limits проекта Dress V и сверить действующий предел. [Настройки API-проектов](https://help.openai.com/en/articles/9186755-managing-projects-in-the-api-platform)
2. **Установить проектный ключ.** Если рабочий провайдер утверждён, создать ключ сервисной учётной записи проекта с минимальными правами и передать его только на Hermes безопасным путём. Подключить его через отдельный systemd credential `openai-api-key`. Межсерверный токен PHP применяется только для связи WordPress с Dress V.
3. **Выполнить один синтетический запрос с разрешения владельца.** Явно выбрать модель и ограничить число вызовов. Сверить расход по Usage проекта и Credit Grants организации. При неопределённом исходе запроса из-за таймаута разобраться с Usage перед любым повтором.
4. **Подтвердить обработку данных перед клиентским пилотом.** Срок жизни файлов в Dress V и PHP относится к нашей инфраструктуре. Для API нужно отдельно проверить регион, основание передачи, политику хранения и настройки проекта.

Для повторной привязки гранта используйте [инструкцию по API-кредитам ChatGPT](https://developers.openai.com/api/docs/guides/chatgpt-api-credits).
